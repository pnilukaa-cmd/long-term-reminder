renewal-reminder — v1 design

Self-contained mockups, one file per screen, each showing loading / empty / error / success (or the closest equivalent) via click-to-switch tabs — no build step, no JS framework, plain HTML/CSS. Token block below is proposed here for the first time (no prior theme existed for this app) and is inlined identically into every file.

Status language (routed q.6) — shape + icon + colour + label, never colour alone

Outlined ring, neutral tone — Upcoming
Filled circle, warning tone — Due soon
Filled, one squared corner (distinct silhouette), error tone — Overdue
Filled circle, success tone, reduced-opacity row — Done

Type category tints (separate colour space from status, on purpose)

Passport / Travel ID — blue
Insurance — teal
Professional Licence — violet
Vehicle (generic) — terracotta, deliberately not amber (status colour)
Warranty — slate blue-grey
Custom / Other — neutral grey
