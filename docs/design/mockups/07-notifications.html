Covers a single ladder-stage notification, a single overdue nag, and the new grouped/summary notification in both its collapsed and expanded states.

Expanded — standard Android inbox-style group, each line independently tappable to that item's detail screen. Mixing an overdue nag with upcoming ladder stages in one group is expected and fine; each line's own status text (e.g. "· overdue") still disambiguates without extra grouping logic. See design doc §6a for what this does and doesn't fix in the worst-case volume math.
