5. Permission prompts

Two separate gates (routed q.1 and a known Android constraint): the notification runtime permission (Android 13+, always needed) and the exact-alarm permission (conditional).

Design recommendation: day/week-granularity reminders (coarsest stage: 6 months; finest: 1 day) don't need minute-precision delivery. Inexact scheduling should be sufficient. I've mocked the exact-alarm screen below so it exists if developer's spike says otherwise — but it's designed as an optional settings-screen link, not an onboarding step, so it can be cut with zero rework if unneeded.
